# Hyprland and UWSM session decision

## External findings

The active integration follows the NixOS Hyprland module and enables `programs.hyprland.withUWSM = true`. This enables the supported UWSM integration and generates the display-manager session entry. The repository does not add a second hand-written Hyprland desktop entry, because competing session definitions make the display-manager and portal behavior harder to reason about.

The Hyprland/Home Manager integration also sets `wayland.windowManager.hyprland.systemd.enable = false`. UWSM owns the compositor session lifecycle; enabling Home Manager's independent systemd integration would create two session owners and can lead to duplicated environment imports, services, or startup hooks.

UWSM is responsible for starting the compositor session. Hyprland owns compositor configuration, while end-4 QuickShell is started from the declarative Hyprland session configuration and communicates through QuickShell IPC. No legacy Lua hook, Ambxst service, DMS service, or custom UWSM desktop entry is part of the active composition.

## Decision

The active NixOS feature is intentionally small:

1. Enable `programs.hyprland.enable` and `programs.hyprland.withUWSM`.
2. Enable Xwayland and the Hyprland XDG desktop portal.
3. Set the greeter default session to the session generated by the NixOS UWSM integration.
4. Keep Home Manager's Hyprland systemd integration disabled.
5. Let the end-4 adapter provide immutable Hyprland and QuickShell assets, while local session and shortcut policy remains in `home/livara/session.nix`.
6. Keep generated palette and QuickShell state in writable user state directories rather than in the Nix store.

If session identity or portal behavior is wrong, diagnose the generated desktop entry and the running environment instead of hiding warnings with a Hyprland watchdog option:

```bash
printf 'XDG_CURRENT_DESKTOP=%s\n' "${XDG_CURRENT_DESKTOP:-unset}"
printf 'XDG_SESSION_DESKTOP=%s\n' "${XDG_SESSION_DESKTOP:-unset}"
loginctl show-session "$XDG_SESSION_ID" -p Type -p Desktop -p Remote
systemctl --user status --no-pager
journalctl --user -b --no-pager | grep -Ei 'uwsm|hyprland|xdg-desktop-portal'
```
